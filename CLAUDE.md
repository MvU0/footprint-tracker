# Footprint-tracker

Lees bij de start van elke sessie eerst @VOORTGANG.md. Dat bestand beschrijft de status, de werkafspraken, de keuzes uit eerdere sessies en de volgende stap.

Kort:
- Communiceer in het Nederlands. De gebruiker kent Python en R, maar geen JavaScript. Houd de code simpel en leg kort uit.
- Werk stap voor stap volgens PLAN.md. Laat na elke stap zien wat werkt en wacht op akkoord.
- Verzin geen cijfers. Nederlandse bronnen gaan voor. Leg de herkomst vast in BRONNEN.md.
- Tests met `npm test`. Werk VOORTGANG.md bij na elke afgeronde stap.
